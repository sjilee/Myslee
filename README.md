# Sung Lee Personal Website

A simple static personal website for Sung Lee.

## Preview

Open `index.html` directly or run a local static server:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Private source material

The original resume source is stored locally under `private/`. This directory is ignored by Git
so that detailed resume content and contact information are not published with the site source.
