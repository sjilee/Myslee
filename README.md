# Sung Lee — Personal Website

A concise, story-led personal portfolio for Sung Lee. The site is intentionally simple: static HTML, CSS, and a tiny JavaScript enhancement for the footer year.

## Run locally

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Private source material

The raw resume notes are stored locally under `private/`. That directory is git-ignored so personal source material and contact details are not committed to version control. Public website copy is a short, approachable adaptation.
