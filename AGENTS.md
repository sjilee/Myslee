# Repository Purpose

This repository contains Sung Lee's personal website. It presents a clear, approachable overview
of Sung's work as a strategic program leader: turning complex technology initiatives into plans
that teams can understand, execute, and improve together.

## Site Goals

- Keep the public story personal, concise, and easy to understand.
- Use plain language instead of resume-heavy terminology.
- Preserve the warm editorial visual style and the bold opening: "Hi, I'm Sung Lee."
- Maintain a lightweight static site that is easy to publish and update.

## Structure

- `index.html`: Page content and semantic structure.
- `styles.css`: Brand styling, layout, responsive behavior, and animation.
- `script.js`: Small client-side enhancements.
- `README.md`: Local preview instructions.
- `private/`: Local-only resume source material. This directory is intentionally ignored by Git.

## Privacy Boundary

Do not commit files from `private/`. Do not publish phone numbers, detailed resume source material,
or other personal information unless Sung explicitly requests it. Public copy should remain
high-level and welcoming.
